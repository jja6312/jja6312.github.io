OCI CLI — 입력과 조회의 설계

“필수 옵션”과 “사람이 입력해야 하는 값”은 다릅니다.

공식 스키마의 정확성은 유지하고, 입력·자동 조회·선행 조건을 한 기준으로 판단합니다. 브라우저는 명령을 만드는 도구이며 OCI 실행 주체는 사용자의 터미널입니다.

01. 전체 구조와 실행 경계

공식 원천은 무엇을 실행할 수 있는지 정의하고, 운영 Overlay는 사람이 어떻게 완주하는지 보충합니다. 보호 데이터 잠금 해제는 OCI 로그인과 별개입니다.

02. 입력 상태는 한 번만 판정

기존에는 preflight만 자동 조회를 인정했습니다. 이제 폼·Alt+I·실행 전 확인이 같은 상태를 읽습니다. 자동 상태는 “이미 조회됨”이 아니라 “실행 시 조회 가능”입니다.

03. Subscription ID — 메뉴 왕복 없는 선택

현재 프로필·리전과 초안은 유지합니다. 조회 명령의 JSON 출력을 붙여넣으면 ID를 명시적으로 선택할 수 있습니다. 다른 exactName 조회에도 같은 연결 패널을 사용합니다.
